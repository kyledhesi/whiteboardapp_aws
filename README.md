# Whiteboard App (AWS)

A real-time collaborative whiteboard built with Node.js, Express, and Socket.io.

This was a university group project — the task was to take an existing whiteboard application and deploy it to the cloud (AWS).

## Tech Stack
- Node.js / Express
- Socket.io (real-time drawing sync)
- AWS

## Running the whiteboard app
Clone the repo to local machine

```bash
npm install
npm start
```
